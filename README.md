# SAT Canopy Colorways

**Open it:** https://badriyahs.github.io/SATCanopyColorways/

A color tool for Badriyah Alsalem's canopy fabric for the Sharjah Architecture Triennial. Try colors on the actual artwork, layer by layer, over a linen ground, and export the result.

## What you can do

- **Recolor any part.** Every row (thread, lettering, marks, grids, rings, holes) has its own color, opacity and eye to hide it. Each layer has an eye and an opacity too.
- **Start from a version.** *Canopy versions* brings back v1 orange, v2 red or v3 white exactly.
- **See it backlit.** *Sun behind* shows the canopy from underneath with the sun shining through.
- **Change the labels.** Show all four lines or just the Arabic and transliteration, set their sizes and weight, and pick the Arabic lettering from the file or the new font.
- **Save colorways.** *Save colorway* keeps your versions in your own browser so you can switch between them.
- **Export.** *Export* downloads a full-size SVG (120 × 120 in), split into EMBROIDERED / PRINT / CUT layers, ready for Illustrator or Rhino.

Drag to pan. Pinch, or hold ⌥ and scroll, to zoom.

The page is a single self-contained HTML file. Nothing you change is sent anywhere: colors and saved colorways stay in your browser.
